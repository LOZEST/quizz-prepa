# Créer une question — guide rapide administrateur

1. Ouvre Quiz TSI et **connecte-toi** avec ton adresse e-mail et ton mot de passe.
2. Dans le menu, ouvre **Banque de questions**.
3. Clique sur **Créer une question**.
4. Choisis le type : question de cours, formule ou exercice avec valeurs variables.
5. Sélectionne la partie, le chapitre, la notion et la difficulté.
6. Écris l'énoncé, l'indice si besoin et une correction détaillée. Les boutons permettent d'ajouter du texte, une formule ou une étape.
7. À l'étape 4, vérifie l'aperçu exactement comme le verra l'élève. Pour un exercice variable, contrôle les dix variantes proposées.
8. Choisis **Enregistrer comme brouillon**, **Publier dans mes questions** ou, si le contenu convient à toute l'équipe, **Publier pour tous**.

Aucun JSON ni SQL n'est nécessaire dans le parcours normal. En cas de doute, garde la question en brouillon afin de la relire plus tard.
