# Sauvegardes Drive

Une sauvegarde manuelle est un snapshot validé et signé par SHA-256. **Complète** inclut explicitement les brouillons vectoriels; **légère** les exclut. Événements, tests, résultats, préférences, versions et manifest sont inclus. Clé, secret, cache, application et KaTeX sont exclus. La liste expose date, type, taille, versions, validité du checksum, compteurs et présence de brouillons sans télécharger chaque contenu. Une suppression demande sa confirmation propre.
